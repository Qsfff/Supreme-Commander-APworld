# Supreme-Commander-APworld
Setup instructions:
1. Install FAF from https://www.faforever.com/ and launch a game with all UI mods you want to be on. Also make sure to set up all settings and hotkeys for your liking
2. Install apworld
3. Download client and unpack it somewhere. Unfortunatly archipelago only supports clients written in python for using them in launcher, so i had to make it standalone.
4. Launch client and go to settings
   
There fill 2 folders with what you have in FAF settings. You need to copy their paths like i did on these screenshots. You can also choose what color you will be playing as.

5. Now you can create a yaml, generate a world with it like you do with every other apworld and connect to it on connect screen of client
<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/54b71fb4-7f3a-43e1-8c88-24ca106c5e9f" />
6. After connecting in launcher tab buttons will appear. You can press them to launch unlocked mission. To unlock a mission a nearby mission must be completed first and top left mission is always unlocked. Bottom right mission must be beaten to beat this apworld.
<img width="1919" height="1080" alt="image" src="https://github.com/user-attachments/assets/eb11ec7d-982d-4b4e-a1cb-33b320faafe5" />
7. You can save during missions, but be aware that game will not be able to load a different map than you launched

# KNOWN BUGS:
After completing a mission nothing happens, but you can quit manually by pressing Alt+F4.
I havent figured out why this happens, but it is not critical.

Sometimes game just frezees and crashes soon after loading in. I have no clue why this happens, but deleting unused mods from your mod folder can help.
